LocalBite: discovery, direct dine-in QR ordering, takeaway pickup scheduling and shared restaurant operations. Read PS1-ALIGNMENT.md and README in any project. Restaurant owners must set actual prices and stock, enable pilot orders, then publish. Native orders use Pay at restaurant; no online payment or live restaurant onboarding is claimed. The hosted developer Worker uses D1 for operations and R2 for spotlight/table-link configuration. Local frontend copies point at that private service; localhost is not authorized for management writes. Node.js 20.9+: npm install then npm run dev in the selected frontend folder. Video assets are stored once under customer/public/reels and copied to management sites by their configs. Menu photographs are stored once under customer/public/menu and copied to management sites on local startup.
